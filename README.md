# 🦖 꼬질룡 (KKOJILRYONG)

> **"코딩 1도 몰랐는데, 네가 좋아서 배웠어."**

VS Code 한 구석에 사는 비뚤빼뚤한 검은 선 공룡. 네가 코드를 칠 때마다 어깨너머로 슥 보고, 똥 같은 코드엔 빡치고(귀엽게), 멋진 코드엔 막춤 추고, 매일 밤 본 걸로 일기(`.txt`)를 쓴다. 그리고 **한 번 같이 공부한 건 절대 안 까먹는다.**

기획 전문은 [`꼬질룡_기획서.md`](./꼬질룡_기획서.md) 참고.

---

## 핵심 설계

- **BYOK (Bring Your Own Key)** — Gemini API 키는 네 거, 비용도 네 거. 우리는 키를 보관하지도 마진을 떼지도 않는다. 키는 `settings.json`이 아니라 VS Code **SecretStorage**에 들어간다.
- **The Eye** (`src/eye`) — 타이핑 멈춤/저장을 디바운스로 어깨너머 관찰. 메인 스레드 안 막는 백그라운드 평가.
- **The Brain** (`src/brain`) — 코드에서 개념을 뽑고, RAG에 비추어 아는 것/처음 보는 것을 가르고, 빡침/춤/평온을 판정한다.
- **The Heart** (`src/heart`) — 평가 + 시간/방치 맥락으로 감정 상태를 전이(평온/집중/기쁨/분노/감동/졸림/삐짐/걱정).
- **The Memory = RAG** (`src/rag`) — 꼬질룡의 심장. 한 번 본 개념을 **임베딩과 함께 영속 저장**하고, 의미 기반(코사인 유사도)으로 회상한다. 재설치해도 살아남는다.
- **The Pen** (`src/diary`) — 세션 끝에 그날 본 걸 짧고 귀여운 일기 `.txt`로 남기고, 새 개념을 RAG에 새긴다.
- **얼굴** (`src/face` + `media/`) — webview에 상주하는 캐릭터. 검은 선 한 겹 SVG + `steps()` 끊김 애니(막춤/파닥파닥/꾸벅).

### 진짜 그림체: Gemini 생성 + remove.bg 누끼

기본은 가벼운 인라인 SVG지만, **Gemini 멀티모달로 제대로 된 손그림 꼬질룡 이미지**를 자세별로 뽑을 수 있다.

```
포즈 프롬프트(외형 고정 + 자세만 교체)
   → Gemini 이미지 생성 (배경 꽉 참, 누끼 X)
   → remove.bg API로 배경 제거 → 투명 PNG     ← 매 생성 끝마다 고정된 단계
   → globalStorage/poses/<id>_<i>.png 캐시       ← 자세별 고정(한 번 만들면 재사용)
```

- 외형 일관성은 `persona.ts`의 `APPEARANCE_PROMPT`를 모든 포즈에 못 박아 유지(검은 선 한 겹, 색칠 없음, 비뚤빼뚤).
- 누끼가 깨끗하게 떨어지도록 포즈 프롬프트가 배경을 **순백(#FFFFFF) 단색 + 그림자/바닥 없음**으로 강제 → remove.bg가 한 방에 따냄.
- 포즈 정의/프롬프트: `src/face/poses.ts` (평온/집중/기쁨(막춤 3프레임)/분노(2프레임)/감동/졸림/삐짐/걱정 + 드래그/쓰담).
- 막춤·빡침 같은 다중 프레임은 webview가 `frameMs` 간격으로 끊기게 순환("끊기는 게 귀엽다").
- 캐시에 포즈가 있으면 PNG, 없으면 SVG로 자동 폴백.

**쓰는 법:**
1. `꼬질룡: remove.bg API 키 등록` ([키 발급](https://www.remove.bg/dashboard#api-key))
2. `꼬질룡: 포즈 이미지 생성` → Gemini로 그리고 remove.bg로 누끼 따서 캐시
3. 끝. 이후 감정 바뀔 때마다 캐시된 투명 PNG로 등장.

> remove.bg 키도 SecretStorage에. BYOK 동일 — 키도 비용도 사용자 거.

### RAG가 만드는 "성장"

꼬질룡은 처음엔 아무것도 모른다(`MemoryStore.size === 0`). 네 코드를 보며 개념을 만나고, 일기에 적은 순간 RAG에 학습된다. 다음에 같은 개념을 다시 만나면 — 임베딩 유사도로 회상해서 — "아 이거 알아!" 한다. 어제 모른다고 한 건 오늘도 모르고, 어제 배운 건 오늘 안다. 이 **점진성과 일관성**이 캐릭터의 진정성을 만든다.

## 써보기

```bash
npm install
npm run compile
```

VS Code에서 `F5` (→ "꼬질룡 실행"). 새 창이 뜨면:

1. `꼬질룡: Gemini API 키 등록 (BYOK)` 커맨드 실행 ([키 발급](https://aistudio.google.com/apikey))
2. 사이드바 🦖 아이콘 클릭 → 꼬질룡 등장
3. 아무 코드나 짜보기. 저장하면 슥 본다.

### 커맨드

| 커맨드 | 하는 일 |
|---|---|
| `꼬질룡: Gemini API 키 등록 (BYOK)` | SecretStorage에 키 저장 |
| `꼬질룡: 오늘의 일기 보기` | 오늘 `.txt` 열기 |
| `꼬질룡: 지금 일기 쓰기` | 지금까지 본 걸로 일기 생성 |
| `꼬질룡: 꼬질룡이 아는 것` | RAG 기억 통계 |
| `꼬질룡: 쓰다듬기` | 좋아함 |

### 설정 (`kkojilryong.*`)

`geminiModel`, `embeddingModel`, `imageModel`(비우면 SVG만), `diaryFolder`, `debounceMs`, `reduceMotion`, `mute`.

## 프라이버시

코드 분석·일기·기억은 **로컬**에 남는다(일기 `.txt`, RAG는 globalStorage JSON). Gemini 호출은 네 키로 직접 — 우리 서버를 거치지 않는다. 일기 폴더는 삭제해도 안 지운다(추억). (기획서 §14)
