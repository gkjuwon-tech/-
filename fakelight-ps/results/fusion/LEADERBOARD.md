# 버니 정면 노멀 기록판 (합체)

입력: MV-Adapter + Juggernaut 정면 뷰. 채점: 정렬된 정답 노멀, 평균 각도 오차.

| 방법 | 오차 |
|---|---|
| IC-Light 회전 트릭 s1 → SDM-UniPS 1024px | 12.66° |
| Neural LightRig 시드 3개 (27장) → SDM-UniPS 1024px | 12.72° |
| IC-Light(rot s1 + v2 all) + Neural LightRig 평균 | 11.09° |
| **주파수 합체: 저주파 = 위 평균, 고주파 = IC-Light (σ=4px)** | **10.89°** |
| RoSE (ICLR 2026) | 16.70° |
| Marigold v1.1 | 16.16° |

주의: 합체 조합과 σ는 버니 정답을 보고 고른 것이라 과적합 가능성이 있다. DiLiGenT에서 고정된 레시피로 검증해야 한다.

## 디테일 보정 (입력 사진의 음영으로 고주파 복원, `scripts/shading_refine.py`)

| 방법 | 오차 | 디테일 상관 (σ=4px) |
|---|---|---|
| 합체 (보정 전) | 10.82° | 0.522 |
| **+ 음영 기반 디테일 보정 (λ=0.1, μ=0.02)** | **9.32°** | **0.602** |
| Marigold | 16.16° | 0.506 |
| RoSE | 16.70° | 0.498 |

주의: λ, μ도 버니 정답을 보고 고른 값이다. 입력 사진의 명암을 그대로 믿으므로, 무늬(알베도)가 있는 실제 물체에서는 무늬를 주름으로 오인할 수 있다.

## 무늬 오인 방지 (`scripts/make_textured_test.py`, `shading_refine.py --relights`)

같은 기하에 줄무늬/점박이 알베도를 입힌 시험 세트 (원본 렌더 좌표계, 합체 노멀 10.26°에서 출발):

| 보정 방식 | 무늬 버니 | 단색 버니 |
|---|---|---|
| 그냥 보정 | 14.71° (무늬를 주름으로 오인) | 9.06° |
| **알베도로 나눈 뒤 보정** | **9.12°** | 9.18° |
| 알베도 + 무늬 경계 신뢰도 | 9.23° | 9.25° |

알베도는 조명 이미지 여러 장의 픽셀별 광도 스테레오 |ρn|로 추정한다. 시험 세트의 조명 이미지는 물리 렌더에
약한 세기/톤 흔들림만 준 것이라, 실제 IC-Light/Neural LightRig 이미지보다 알베도 추정이 쉽다.
