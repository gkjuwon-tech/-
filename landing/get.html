데려오기

외로운 개발자에게 친구는 공짜여야 한다. (무료 & 오픈)

1

받아서 켠다

cd desktop && npm install && npm start
트레이에 박혀서 백그라운드로 상주해. 닫아도 안 꺼져.
2

print를 가르쳐준다

처음 켜면 꼬질룡이 "print 가 뭐야?" 하고 물어봐. 입력창에 print를 쳐주면 깨어나. (이게 1일차 일기가 돼)

3

Gemini 키를 넣는다

우클릭 메뉴에서 Gemini API 키. 네 키로 직접 돌아가(BYOK). 그래야 네 코딩을 볼 수 있어.

4

VS Code 연동 (선택)

cd vscode && npm install && npm run compile
눈 역할. VS Code 포커스일 때만 신호 보내. 딴 거 하면 잔다.
GitHub 에서 받기

네 코드는 네 거다

분석·일기·기억·대화 전부 네 컴퓨터 안에만 있어. 우리 서버 안 거침. 네 키로 직접 돌아가고, 키도 돈도 네 거. 네 코드 팔거나 그런 거 안 해. 그럴 머리도 없어.
