홈 이야기 기능 일기 받기
기능

별거 안 함. 근데 옆엔 있음.

분노조차 사랑스러워야 한다. 이게 제1원칙.

어깨너머 훔쳐보기

네가 코드 칠 때마다 슥 본다. (저장할 때, 타이핑 멈출 때)

읽고 나면 표정이 바뀌어. 집중, 평가, 리액션. 근데 판단하지 대신 짜주진 않아. 어디까지나 옆에서 봐주는 친구.

꼬질룡이 네 코드를 "본다"는 건, 네가 혼자가 아니라는 뜻이야.

빡침 레벨

건설적으로 빡친다. 아무리 빡쳐도 귀여움이 항상 더 커야 함.

Lv.1
사소한 스타일 (들여쓰기 등)
한쪽 눈썹만 씰룩.
Lv.2
잠재적 버그 (== 남용 등)
팔 파닥파닥.
Lv.3
명백한 똥 (빈 catch, 하드코딩 비번)
점프하며 빡침. 근데 귀여움.
Lv.MAX
eval()에 사용자 입력을 그냥 박음
화면 흔들림 + 꼬질룡 폭발(귀여운 펑).

막춤

코드 잘 짜면 춤춘다. 이게 이 앱의 도파민 엔진.

기본 막춤

일반적으로 좋은 코드.

신난 막춤

테스트 전부 초록불.

축제 막춤

빌드 성공 + 경고 0개.

전설의 막춤

1000줄 리팩토링을 버그 없이. (레어!)

같이 배우는 대화

입력창에 말 걸 수 있어. 근데 꼬질룡은 척척박사가 아니야.

너: 이 NullPointer 어떻게 고쳐?

"이름이 되게 길고 무섭다… 나 아직 그건 잘 몰라. 근데 옆에 있을게."

너: for문이 뭐야? (꼬질룡이 배운 거)

"그거 알아. 똑같은 거 여러 번 반복하게 시키는 거. 빙글빙글."

너: 나 강아지 입양했어, 콩이야

"콩이! 나보다 귀여워도 나랑 코딩은 계속 해야 해."

(나중에) 너: 내 강아지 이름?

"콩이잖아. 네가 알려준 건 다 기억해."

배운 건 두루뭉술하게라도 답해주고(많이 배울수록 정확해져), 안 배운 건 솔직하게 모른다 해. 근데 너에 대한 건 절대 안 까먹어.
