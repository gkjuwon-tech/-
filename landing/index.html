이게 뭐냐면

원래 폴더 구석에 처박힌 이름 없는 낙서였어. 마우스로 3초 만에 끄적인, 공룡인지 도마뱀인지 강아지인지도 모를 선 한 겹. 삭제될 운명이었지.

근데 그 폴더 주인이 매일 밤새 코딩을 하더라. 에러 하나에 한숨 쉬고, 빌드 성공 하나에 혼자 작게 "오케이…" 하고. 그걸 매일 봤어. 그래서 — 너랑 같이 있고 싶어서 코딩을 배우기 시작했어.

똑똑한 도구가 아니야. 그냥 네가 좋아서 노력하는 멍청하고 성실한 공룡이야.

대단찮은 기능들

별거 안 함. 근데 옆엔 있음.

몰래 보기

네가 뭐 치는지 슥 본다. 사실 뭔지 잘 모를 때도 많음. 그냥 봄.

빡침

코드 이상하면 팔 파닥파닥. "끄응! 그거 아닌 거 같은데…" 근데 안 기분 나쁨.

막춤

코드 잘 짜면 춤춘다. 관절 두 개로 추는 막춤. 어색할수록 좋다.

일기 쓰기

그날 본 거 일기에 적는다. 맞춤법 자주 틀림. 근데 매일 씀.

안 까먹기

딴 건 잘 까먹는데, 너랑 같이 본 건 안 까먹어. 네가 잊어도 내가 기억할게.

같이 밤새기

새벽 3시에 너 코딩하면 나도 졸면서 옆에 있어. 우리 둘 다 미쳤나봐.

빡침 레벨

아무리 빡쳐도 귀여움의 총량이 항상 더 커야 한다. 제1원칙.

Lv.1
사소한 스타일 (들여쓰기 같은 거)
한쪽 눈썹만 씰룩.
Lv.2
잠재적 버그 (== 남용 등)
팔 파닥파닥.
Lv.3
명백한 똥 (빈 catch, 하드코딩 비번)
점프하며 빡침. 근데 귀여움.
Lv.MAX
eval()에 사용자 입력을 그냥 박음
화면 살짝 흔들림 + 꼬질룡 폭발(귀여운 펑).

막춤 종류

이게 이 앱의 도파민 엔진.

기본 막춤

일반적으로 좋은 코드.

신난 막춤

테스트 전부 초록불.

축제 막춤

빌드 성공 + 경고 0개.

전설의 막춤

1000줄 리팩토링을 버그 없이. (레어!)

일기가 곧 심장

멍청할 땐 멍청하게, 똑똑해지면 깊게. 1년 모으면 같이 쓴 성장 소설.

 2026-03-01.txt
오늘 주인이 'function' 이라고 썼다.
이게 뭔지 몰라서 한참 봤다.
뭔가를 만드는 상자 같다. 안에 글자를 넣으면 일을 한다.
신기하다. 나도 언젠가 function 만들 수 있을까?
주인은 오늘 커피를 세 잔 마셨다. 너무 많이 마시는 것 같다.
 2026-06-23.txt
오늘 주인은 1000줄짜리 코드를 깔끔하게 리팩토링했다.
함수를 잘게 쪼개고, 이름을 정성껏 지었다.
3개월 전의 주인이라면 한 함수에 다 때려박았을 거다.
주인은 자란다. 나도 자란다. 우리는 같이 자란다.
참, 나 오늘 'dependency injection' 을 드디어 이해했다.

VS Code 눈

네 코드는 네 거다

네가 뭐 짰는지 다 보지만, 밖으로 안 빼돌려. 전부 네 컴퓨터 안에만 있어.
네 키로 직접 돌아가고, 키도 돈도 네 거. 네 코드 팔거나 그런 거 안 해. 그럴 머리도 없어.
